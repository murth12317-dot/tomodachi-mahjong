# 友達麻雀（四人打ち・友達対戦専用）

ブラウザで遊べる、天鳳/MJ風の四人麻雀です。部屋番号（4桁）を共有して友達と対戦できます。
人数が足りないときは CPU を入れられます。**追加パッケージ不要**（Node.js だけで動きます）。

## ルール
「友達麻雀 ルール定義書」（B-12〜B-19、R-17〜R-44）どおりに固定です（部屋ごとの設定はありません）。
- 東風戦・25000点持ち・ポイントなし（着順祝儀 1着+30枚・2着+10枚・3着−10枚・4着−30枚）、常に東西場、1本場1500点
- 親は和了・聴牌流局のとき続行／流すを選択（20秒で続行）、55000点コールド、トビ（祝儀10枚）
- 5はすべて特殊牌（赤・金・青・虹）、白發中にぽっち（倍ぽっち・發ぽっち・中ぽっち）
- 祝儀：特殊牌・裏ドラ・一発・高打点・役（チャンタ・純チャン・一通）・七対子4枚使い・1翻和了・流し満貫・コールド・トビ
- オープンリーチ、包（大三元・大四喜）、人和（倍満）、切り上げ満貫、ダブル／トリプル役満、途中流局なし
- オールマイティなどで和了の取り方が複数あるときは、和了した人が画面で選択（20秒で祝儀が一番多いもの）
- 細かい挙動は天鳳ルールに準拠

## 手元で動かす
```
node server.js
```
→ ブラウザで http://localhost:3000 を開く。  
同じWi-Fiの友達は `http://<このPCのIPアドレス>:3000` で参加できます。

## ネットに公開して遠くの友達と遊ぶ（Render 無料プラン）
1. https://github.com でアカウントを作り、新しいリポジトリ（例：`tomodachi-mahjong`）にこのフォルダの中身をすべてアップロード
   （ブラウザの「Add file → Upload files」にフォルダの中身をドラッグでOK）
2. https://render.com で「GitHubでサインアップ」
3. **New → Blueprint** → さっきのリポジトリを選ぶ → `render.yaml` の設定（無料プラン）がそのまま使われるので **Apply**
   （Blueprint が出ないときは **New → Web Service** → Start Command `node server.js`、プラン Free）
4. 数分で `https://tomodachi-mahjong-xxxx.onrender.com` のようなURLができる。開いて部屋を作り、招待リンクを友達に送る

※ 無料プランは15分ほど誰も使わないと休止し、次に開いたとき起動まで少し（1分ほど）待ちます。  
※ 部屋・成績・牌譜はサーバーのメモリにあるので、休止・再起動で消えます。残したいときは終局画面の「成績と牌譜を保存」。  
※ GitHub のファイルを更新すると、Render が自動で新しい版に入れ替えます（対局中の部屋は消えます）。

## iPhone でアプリのように使う（無料）
1. Safari で公開したURLを開く
2. 共有ボタン（□に↑）→「ホーム画面に追加」→「追加」
3. ホーム画面の「友達麻雀」アイコンから、全画面で起動できます  
   Android（Chrome）はメニュー →「ホーム画面に追加」／「アプリをインストール」

## ファイル構成
- `server.js` … HTTPサーバー（部屋管理・通信。Server-Sent Events + POST）
- `game.js` … 対局エンジン（配牌・鳴き・リーチ・流局・半荘進行）と CPU
- `yaku.js` … 和了判定・役・符・点数計算
- `public/` … 画面（HTML/CSS/JS）。`stats.js` は成績表（終わった半荘を端末に記録し、週ごとの集計・CSV保存）
- `test/test.js` … テスト（`npm test`：役・点数のテスト + CPU同士40局の自動対局）

## 実装上の判断（定義書に書かれていない部分）
- ダブロン・三家和で取り方の候補が複数あるときは、自動で祝儀が一番多いものを選択
- オープンリーチへの強制放銃は、役満払い（点数・役満の祝儀40枚）
- 流し満貫のときは本場・テンパイ料なし（天鳳と同じ）
- 打牌・鳴きの持ち時間はなし（N-06）。結果画面は30秒で自動的に次へ
